[topic] Алгебра 7кл §11. Умножение многочленов

[easy]
Выполни умножение: $(b + 1)(b + 4)$. Пиши без пробелов маленькими латинскими буквами, степень через ^, например: b^2+5b+4
= b^2+5b+4
---
[easy]
Выполни умножение: $(a - 3)(a - 2)$. Пиши без пробелов: a^2-5a+6
= a^2-5a+6
---
[easy]
Выполни умножение: $(a - 2)(a + 6)$. Пиши без пробелов: a^2+4a-12
= a^2+4a-12
---
[easy]
Выполни умножение: $(b + 7)(b - 1)$. Пиши без пробелов: b^2+6b-7
= b^2+6b-7
---
[easy]
Выполни умножение: $(5 + a)(3 + a)$. Пиши без пробелов: a^2+8a+15
= a^2+8a+15
---
[medium]
Представь в виде трёхчлена: $(2a - 1)(a - 3)$. Пиши без пробелов: 2a^2-7a+3
= 2a^2-7a+3
---
[medium]
Представь в виде трёхчлена: $(3b - 2)(4b + 5)$. Пиши без пробелов: 12b^2+7b-10
= 12b^2+7b-10
---
[medium]
Представь в виде многочлена стандартного вида: $(4m + n)(m + 4n)$. Пиши без пробелов, латиницей: 4m^2+17mn+4n^2
= 4m^2+17mn+4n^2
---
[medium]
Представь в виде многочлена стандартного вида: $(5a + 2b)(3a - 2b)$. Пиши без пробелов: 15a^2-4ab-4b^2
= 15a^2-4ab-4b^2
---
[medium]
Представь в виде многочлена стандартного вида: $(a^2 - 2a + 5)(a - 1)$. Пиши без пробелов: a^3-3a^2+7a-5
= a^3-3a^2+7a-5
---
[medium]
Представь в виде многочлена стандартного вида: $(2 - 3c)(-c^2 - 4c + 7)$. Пиши без пробелов: 3c^3+10c^2-29c+14
= 3c^3+10c^2-29c+14
---
[medium]
Упрости выражение: $(c - 6)(c + 8) - 3c$. Пиши без пробелов: c^2-c-48
= c^2-c-48
---
[medium]
Упрости выражение: $(5a - 3)(2 - 3a) + 15a^2$. Пиши без пробелов: 19a-6
= 19a-6
---
[hard]
Выполни умножение двучленов: $(2x - 1)(2x + 1)(4x^2 + 1)$. Пиши без пробелов: 16x^4-1
= 16x^4-1
---
[hard]
Выполни умножение двучленов: $(a - 1)(a - 2)(a - 3)$. Пиши без пробелов: a^3-6a^2+11a-6
= a^3-6a^2+11a-6
---
[hard]
Упрости выражение: $(x + 3y)(x + y + 2) - (x + y)(x + 3y + 2)$. Пиши без пробелов: 4y
= 4y
---
[hard]
Упрости выражение: $(a + 5b)(a - b + 3) - (a - b)(a + 5b - 3)$. Пиши без пробелов: 6a+12b
= 6a+12b
---
[hard]
Реши уравнение: $(x - 1)(x + 2) - (x + 4)(x - 5) = 12$. Ответ — число (корень уравнения).
= -3
---
[hard]
При каком значении $x$ значение выражения $(4x - 1)(2 - 3x)$ на 2 больше значения выражения $2x(5 - 6x)$? Ответ — число.
= 4
