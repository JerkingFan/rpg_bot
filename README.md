# RPG-бот для математики

Telegram-бот на **aiogram 3** + **SQLAlchemy async** + **SQLite**, который превращает
домашние задания в RPG-петлю: ученик решает задачи, получает XP и монеты, качает
навыки, открывает темы и сражается с боссами.

Главное правило: **RPG-прогресс нельзя получить, просто нажав кнопку**. XP, монеты
и мастерство начисляются только за ответ, который прошёл проверку. Задачи без
эталонного ответа уходят учителю на ручную проверку.

## Петля игрока

1. **Квест дня** — 3 задачи. За каждую правильную задачу дают XP, монеты и
   мастерство темы.
2. **Навыки** — алгебра, геометрия, тригонометрия, производные. Каждый навык
   качается отдельно.
3. **Карта знаний** — темы с процентом мастерства. Текущая тема подсвечена.
4. **Босс темы** — 5 HP у босса и 3 сердца у ученика, до 7 задач. Победа даёт
   крупную награду и мастерство, поражение — просто повод потренироваться.
5. **Магазин** — подсказки, заморозка стрика и косметика за монеты.

Анти-фарм:

- повторное решение той же задачи даёт 0 XP (только 2 монеты за практику);
- дневные лимиты XP и монет;
- подсказка снижает награду;
- одна попытка на задачу: ошибся — сразу показывается правильный ответ;
- задачи без эталона не дают XP до проверки учителем.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# вставь BOT_TOKEN и ADMIN_IDS

python main.py
```

`.env`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789
DATA_DIR=
DATABASE_URL=sqlite+aiosqlite:///bot.db
DAILY_TASK_TIME=18:00
TIMEZONE=Europe/Minsk
WEBAPP_URL=https://bot676767.bothost.tech
PORT=8080
WEBAPP_DEV_MODE=
```

При старте бот сам создаёт таблицы, добавляет недостающие колонки в существующую
SQLite-базу и заполняет базовые предметы/квесты.

### Где лежит база (важно для хостинга)

`bot.db` не хранится в git. На bothost между деплоями сохраняется только
каталог `/app/data`, поэтому база должна лежать там:

```env
DATA_DIR=/app/data
DATABASE_URL=sqlite+aiosqlite:////app/data/bot.db
```

Можно указать только `DATA_DIR=/app/data` — относительный
`DATABASE_URL=sqlite+aiosqlite:///bot.db` автоматически превратится
в `/app/data/bot.db`.

Перед каждым запуском бот:

1. создаёт каталог базы, если его нет;
2. переносит старую `./bot.db` в постоянный каталог, если база там ещё не создана;
3. делает резервную копию в `backups/` рядом с базой (`/app/data/backups`),
   хранит последние 10 копий.

В логах при старте печатается абсолютный путь к базе — по нему видно,
что прогресс пишется на постоянный диск.

## Telegram Mini App

Бот и Mini App работают в **одном процессе**: aiogram делает long polling,
а FastAPI/uvicorn отдаёт интерфейс и API на `0.0.0.0:$PORT`. База, проверка
ответов, XP, монеты, магазин и боссы — те же самые, что и в боте.

Переменные окружения:

```env
WEBAPP_URL=https://bot676767.bothost.tech
PORT=8080
WEBAPP_DEV_MODE=
```

- `WEBAPP_URL` — публичный HTTPS-адрес приложения. По нему Telegram открывает
  Mini App из кнопки «🎮 Приложение» и из команды `/app`.
- `PORT` — внутренний порт контейнера. На bothost он должен совпадать с портом,
  который указан в настройках веб-приложения/домена.
- `WEBAPP_DEV_MODE=1` — только для локальной разработки: разрешает запросы
  с заголовком `X-Dev-User-Id` без подписи Telegram. В продакшене не включай.

### Настройка bothost

1. В панели bothost включи **«Использовать домен»** для приложения.
2. Укажи домен `bot676767.bothost.tech` и внутренний порт `8080`
   (или тот, что задан в `PORT`).
3. Перезапусти/передеплой проект. HTTPS bothost выдаёт автоматически.
4. Проверь `https://bot676767.bothost.tech/health` — должно вернуться
   `{"ok":true}`.
5. Открой бота и нажми `/app` или кнопку «🎮 Приложение».

Если домен ещё не включён или порт не совпадает, бот продолжит работать,
но Mini App будет недоступен — в логах будет сообщение об ошибке запуска
веб-сервера.

### Сохранение базы при деплое (обязательно)

Mini App и учительская панель **не меняют схему базы** — все данные лежат
в той же `bot.db`. Чтобы деплой ничего не обнулил:

1. В переменных bothost держи:

   ```env
   DATA_DIR=/app/data
   DATABASE_URL=sqlite+aiosqlite:////app/data/bot.db
   ```

2. **Не удаляй** каталог `/app/data` и не делай «чистый» деплой с очисткой
   диска — там лежат ученики, ответы, XP и прогресс.
3. При первом запуске после переезда бот сам перенесёт старую `./bot.db`
   в `/app/data/bot.db`, если постоянная база ещё пустая.
4. В логах при старте смотри строку с абсолютным путём к базе: должно быть
   `/app/data/bot.db`, а не `/app/bot.db`.
5. Резервные копии создаются автоматически в `/app/data/backups`
   (последние 10). Перед крупным обновлением скачай свежую копию из панели.

### Учительская панель

Если Telegram ID есть в `ADMIN_IDS` (или у пользователя `role = "teacher"`),
в Mini App появляется вкладка **«Учитель»**:

- обзор: ученики, ответы на проверке, ошибки, задания, активная тема;
- ученики: карточка, назначение темы и сложности, выдача заданий,
  индивидуальное задание;
- темы: поиск, создание, активация, добавление заданий;
- проверка ответов: засчитать ответ или начислить бонус;
- импорт заданий и дополнение базы (только добавление, без удаления).

Учительские запросы идут на `/api/teacher/*` и проверяются на сервере:
ученик получает `403`. Уведомления ученикам отправляются через того же
бота, что и обычные сообщения. Импорт и «Дополнить базу» не трогают
существующих учеников и их прогресс.

### Локальная проверка

```bash
WEBAPP_DEV_MODE=1 PORT=8080 .venv/bin/python main.py
```

Затем открой `http://127.0.0.1:8080/?dev_user_id=<telegram_id>` — приложение
возьмёт пользователя из локальной базы. Без `WEBAPP_DEV_MODE=1` API принимает
только настоящий `initData` из Telegram.

## Команды

Ученик:

- `/start` — регистрация и главное меню
- `/app` — открыть Mini App
- `/hero` — карточка героя (уровень, ранг, навыки, мастерство)
- `/quest` — квест дня
- `/map` — карта знаний
- `/shop` — магазин
- `/boss` — босс текущей темы
- `/help` — правила

Учитель:

- `/admin` — админ-панель: темы, задания, ученики, проверка ответов, рассылка
- `/start_lesson` — назначить тему и сложность ученику
- `/add_task` — добавить задание в активную тему
- `/stats` — статистика
- вкладка **«Учитель»** в Mini App — те же действия без команд бота
  (доступна, если Telegram ID есть в `ADMIN_IDS`)

## Структура

```
handlers/          # aiogram-роутеры: common, student, teacher, admin_panel
services/
  rpg.py           # персонаж, награды, навыки, мастерство, квесты, магазин, боссы
  answer_checker.py# безопасная проверка ответов (AST вместо eval)
  daily_tasks.py   # выдача 3 заданий в день + долги
  gamification.py  # уровень, стрик, достижения
  latex_renderer.py# рендер формул в картинки
database/
  models.py        # SQLAlchemy-модели
  migrations.py    # лёгкие миграции SQLite
  base.py          # engine, session, init_db
keyboards/         # inline-клавиатуры
webapp/            # FastAPI API + статический интерфейс Mini App
utils/time.py      # UTC в БД, локальные даты для квестов
```

## Миграции

Проект использует `Base.metadata.create_all` + идемпотентные `ALTER TABLE` для
SQLite. Это удобно для небольшого проекта, но для серьёзных изменений схемы лучше
перейти на Alembic. Перед первым запуском на рабочей базе сделай резервную копию:

```bash
cp bot.db bot.db.backup
```

## Безопасность

- Токен хранится только в `.env`; `.env` и базы исключены из git.
- Ответы учеников проверяются безопасным AST-вычислителем: нет `eval`,
  ограничены длина выражения, степень и количество узлов.
- Пользовательский текст экранируется перед отправкой в HTML.
